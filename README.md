# Portfólio — Katherine Uchoa

Portfólio pessoal em português, com identidade editorial em tons pastel e foco em projetos, experimentos e aprendizados em tecnologia.

## Estrutura

- `index.html`: conteúdo e estrutura semântica da página.
- `styles.css`: identidade visual, layout responsivo e estados de interação.
- `favicon.svg`: ícone da página.

## Visualizar localmente

Abra `index.html` em um navegador. Não há etapa de build nem dependências de JavaScript.

A página carrega as fontes DM Sans e Playfair Display pelo Google Fonts. Se as fontes externas não estiverem disponíveis, serão usadas as fontes de sistema definidas como fallback.

## Atualizar conteúdo

Edite o texto diretamente em `index.html`. Atualize também os links sociais e os dados do projeto quando houver novos links, projetos ou informações para apresentar.
